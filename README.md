# WEB 110: Local Guide Project
This website was created for my final project in WEB 110 at Wake Technical Community College

The Arlington Local Guide is intended for visually impaired tourists who are looking for information on local food and dining options as well as how to plan for transportation throughout their visit.

Accessibility was at the forefront of all design choices when building this website. I'm visually impaired myself and am certified in Web Accessibility standards and testing, so I have a decent foundation for building accessible websites. I hope my skills are demonstrated well through this project, and I can't wait to continue learning more in future classes!

## A note for my professor if they read this:
I'm aware that most of my images do not have alt text. The images I used here are non-essential and do not add meaningful information to the user, so they should not have any alt text. Auditing is what I'm passionate about, so I'm a little bit paranoid that I'll be marked down for accessibility issues here.

Thank you for reading, enjoy the website.
